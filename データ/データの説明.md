# データの説明

出入国在留管理庁「在留外国人統計（旧登録外国人統計）」（e-Stat で公開）を、1行に1つの数が入った表に整えたものです。
作り方は `../download_estat.py`（e-Stat から落とす）→ `../make_data.py`（読み出して確かめる）。
元のファイルの出どころ（e-Stat の番号・URL・公開日）は `../元データ/出どころ一覧.csv` にあります。元のファイル（Excel・PDF）は大きいので GitHub には入れていません。この一覧の URL から e-Stat で取れます（`../download_estat.py` で全部落とせます）。

サイトの地図の形（`../site_assets/map/*.json`）は、国土地理院「地球地図日本」第2.1版の行政界（2015年1月1日時点、https://www.gsi.go.jp/kankyochiri/gm_jpn.html ）から `../make_map.py` で作ったものです（国土地理院コンテンツ利用規約による。元の地図のデータは GitHub には入れていません）。

時点は「2025-12」＝2025年12月末。2012年までは年に1回（12月末）、2013年からは6月末と12月末の年2回です。

「〇〇/」の大きな表は、**時点ごとのファイル**に分けています（例：`市区町村_国籍_在留資格/2025-12.csv` が2025年12月末の分）。
1つにまとめると100MBをこえ、Excel でも開けない（約105万行まで）ためです。どのファイルも列は同じなので、つなげればもとの1つの表になります。

## 列

- **統計**：`登録外国人統計`（2011年末まで）か `在留外国人統計`（2012年12月末から）。数え方が違うので、つなげて増え方を見るときは注意
- **人数**：その組み合わせの人数。`国籍・地域` や `在留資格` が「総数」の行は、その地域の合計
- **種別**（市区町村の表）：
  - `市区町村` … ふつうの市町村と東京の23区
  - `区` … 政令指定都市の区（名前は「札幌市中央区」の形）
  - `合計の行` … 政令指定都市の合計と東京の「特別区」（23区の合計）。**区と一緒に足すと二重に数えてしまうので、合計するときは除く**
  - `その他` … 人数の少ない市町村をまとめた行など（下の注意）
- **市区町村コード**：全国地方公共団体コード（2021年12月末からの表だけに入っています）
- **出どころ**：使った e-Stat の表（`t1`・`t2` はテーブルデータから集計したもの）

## 注意

1. **市区町村×国籍は、2023年6月末までは主な国だけ**です（その年に多い8〜10の国と「その他」）。全部の国籍が市区町村ごとに分かるのは2023年12月末から。
2. **2006〜2011年末の市区町村の表は、市と区だけ**です（町村は載っていません）。そのため合計は全国の数より10万人ほど少なくなります。
3. **人数の少ない市町村は国がぼかしています**（個人が分からないようにするため）。
   - 2023年12月末・2024年6月末：外国人が10人以下の市区町村は、全国で1つの「その他」の行（都道府県も「その他」。2023年12月末 363人、2024年6月末 372人）にまとめられています。表にのっている市区町村は、どれも11人以上です
   - 2024年12月末から：10人以下の市町村は、国籍と在留資格が「（秘匿）」になっています（人数は分かります）
   - 2020年12月末・2021年6月末の市区町村×在留資格：小さな市町村が表に載っていないため、都道府県の合計との差を「その他（表にない市町村）」の行にしました
   - 2021年12月末の市区町村×在留資格の表は、総数10人以下の市区町村が載っていません（例：佐賀県玄海町）。表に載っていない市区町村の在留資格は「分からない」で、0人ではありません
   - 国の表にない組み合わせは、0人とは限りません。その時点の表にその区分がない（例：2015年6月末までの「韓国」だけの数）、その市区町村が表に載っていない、などの場合があります。サイトでは「データなし」として、0人と分けて示しています
4. 元の表の書き間違いと思われる所はそのまま残し、合計が合うようにしています（2016年6月末の鳥取県「八頭郡」の行に14人など。「〇〇郡（町村の記載なし）」の行）。
   - 元の表の名前の書き違い：2019年12月末・2020年6月末の表は相模原市の南区が「市南区」と書かれています。表では「相模原市南区」にしています
   - 2021年6月末の市区町村×在留資格の表の「札幌市総数」は、札幌市の区の合計の行です（種別は「合計の行」。区と一緒に足さない）
   - 2016年6月末の熊本市：国の表の市の合計は0人ですが、5つの区の合計は4,704人です。表は国の表のまま（合計の行が0人）。サイトの熊本市の数は区の合計を使っています
   - 2006年12月末の広島市：市の合計（16,559人）と区の合計（16,576人）が17人違います。どちらも国の表のままです
   - 市区町村の名前は国の表のままです（「諌早市」「塩竃市」「篠山市」「八丈島八丈町」など、今と字や名前が違う所も）。2021年6月末までの表には市区町村コードがないため、サイトでは名前で今の市町村に結んでいます（読み替えの一覧は `../make_site.py` の OLD_NAME）。合併して範囲が変わった市町村は結んでいません
   - 浜松市天竜区は2024年1月の区の再編でコードが 22137 から 22140 に変わりました（区の範囲は同じ）。表は国の表のままのコードです。サイトでは1つの区としてつなげています
5. 2015年6月末までは「韓国・朝鮮」が1つの国籍として集計されています（それ以後は「韓国」と「朝鮮」に分かれます）。
   - 国籍・地域の名前は、同じ国の書き方の違い・名前が変わった国・元の表のマスで文字の順が入れ替わっていたもの（2006〜2010年の都道府県の表の「・トバゴトリニダード」など）・中点が半角のもの（2006年末の「韓国･朝鮮」）をそろえています。元の書き方は「国籍・地域の名前の直し.csv」にあります。別の国（ユーゴスラビア・セルビア・モンテネグロ・セルビア・モンテネグロ）はまとめていません
   - 全国の数と都道府県の合計の差は、住む所が「未定・不詳」の人です（全国の数にだけ入る。2025年12月末は7,228人）
   - 浜松市は2024年1月1日に7つの区（中・東・西・南・北・浜北・天竜）が3つの区（中央・浜名・天竜）になりました。表は国の表のままの区です。サイトの浜松市の数は、その時点にあった区の合計です
6. 在留資格の名前は時代で変わります（2015年「投資・経営」→「経営・管理」、「技術」と「人文知識・国際業務」→「技術・人文知識・国際業務」、2017年「介護」、2019年「特定技能」など）。表では元の名前のままにしています。
7. 1959〜2005年の表は、紙の統計書をスキャンした PDF の画像から数字を読み取って作り、`古い表/` に別に置いています（作り方・確かめの結果・注意は `古い表/古い表の説明.md`）。スキャンの PDF も e-Stat から取れます（`../元データ/出どころ一覧.csv`）。
8. `国籍・地域の区分.csv` の **州** は、国の表（国籍・地域別在留資格の表）の「州」の列のとおりです（アジア・ヨーロッパ・アフリカ・北アメリカ・南アメリカ・オセアニア・無国籍）。
   国の表では、**中央アジアとコーカサスの国（ウズベキスタン・カザフスタン・ジョージアなど）は「ヨーロッパ」**、トルコとキプロスは「アジア」、メキシコや中米・カリブ海の国は「北アメリカ」に入っています。
   **地域区分** は、その州の中を、国連の統計の地域分類（M49）をもとにこのサイトで分けたものです（イランは西アジア（中東）に入れています）。国の表にない昔の名前・書き方の州は、このサイトで決めました（「州の出どころ」の列）。

## 不法残留者数（不法残留/）

出入国在留管理庁の報道発表「本邦における不法残留者数について（〇年〇月１日現在）」の Excel から作りました（2021年1月1日〜2026年7月1日の12回分）。
作り方は `../download_fuho.py`（発表の資料を落とす）→ `../make_fuho.py`（読み出して確かめる）。資料の URL と公表日は `../元データ/不法残留_出どころ一覧.csv` にあります。

| ファイル | わかること | ある時点 |
|---|---|---|
| 推移.csv | 国籍・地域別（男女別も）と、在留資格別の数の移り変わり | 2017年〜2020年は1月1日だけ。2021年からは1月1日と7月1日 |
| 国籍_在留資格.csv | 国籍・地域 × 在留資格 | 発表の時点ごと（2021年1月1日〜） |
| 新規.csv | 新規不法残留者数（前の時点のあとに新しく分かった人）と、継続・減少 | 2026年1月1日・2026年7月1日 |
| 確かめ.csv | 内わけの合計が総数と合うか、表どうしで同じ数か、同じ時点の数が発表によって違わないかを確かめた結果 | |

- **不法残留者** は、在留期間が過ぎたあとも日本にいる外国人です（入管法第24条の不法残留の規定に当たる人）。国が出入国の記録などから出した **概数** です。
- 時点は「2026-07-01」＝2026年7月1日。在留外国人統計（6月末・12月末）とは **時点も数え方も違う** 別の統計です。不法残留者は在留外国人統計の数には入っていません（在留期間が切れていて、中長期在留者・特別永住者ではないため）。
- **在留資格** は、不法残留になった時点にもっていた在留資格です。「留学」には、昔の在留資格「就学」（2010年7月1日より前）だった人も入ります。
- 「種別」が `技能実習の内わけ` の行（技能実習1号イ など）は、「技能実習」の行の内わけです。ほかと一緒に足すと二重に数えてしまいます。
- 国籍・地域は、発表ごとの **上位10か国・地域と「その他」** だけです。上位の顔ぶれは発表ごとに変わるので、**「その他」に入っている国は発表によって違います**（同じ時点の「その他」の数が発表によって違うのはこのため）。
- 推移.csv の「状態」：`その発表の時点の数` と、`発表にのった前の時点の数`（発表には前の4時点の列もある）。前の時点の数は、どの発表でも同じでした（あとから直された数はありません。「その他」は上のわけで比べていません）。
- 2016年より前の数は、この Excel には入っていません（発表の資料ではグラフの絵だけ。1990年からの数があり、いちばん多かったのは1993年5月1日の298,646人）。
- 新規.csv の「その他」は、推移の表の「その他」と中身が違います（新規の表は、新規の人の多い国籍・在留資格を上に出しているため）。在留資格別の新規には「出国期間」（在留資格を取り消されたあと、出国のために認められた期間）もあります。
- 確かめの結果：12回分のすべてで、国籍・地域の合計＝総数、男＋女＝総数、在留資格の合計＝総数、技能実習の号の合計＝技能実習、国籍・地域 × 在留資格の縦と横の合計、推移の表と国籍 × 在留資格の表の数、新規＋継続＝その時点の数・継続＋減少＝前の時点の数 が合っています。

## 帰化（帰化/）

法務省民事局「帰化許可申請者数等の推移」（https://www.moj.go.jp/MINJI/toukei_t_minj03.html ）の PDF とページの表から作りました。
作り方は `../download_kika.py`（ページと PDF を落とす）→ `../make_kika.py`（PDF の文字の位置から読み出して確かめる）。資料の URL は `../元データ/帰化_出どころ一覧.csv` にあります。

| ファイル | わかること | ある年 |
|---|---|---|
| 帰化の推移.csv | 帰化許可申請者数・帰化許可者数（総数と、韓国・朝鮮／中国／その他）・帰化不許可者数 | 1952年〜2025年 |
| 国籍別帰化許可者数.csv | 帰化許可者数の上位10か国・地域と「その他」「総数」（2019〜2022年は前の版の保存版から。「保存版のURL」の列） | 2019〜2025年 |
| 国籍取得と離脱.csv | 国籍取得者数（届け出で日本の国籍を取った人。国籍法第3条・第17条など。帰化とは別）と、国籍離脱者数（国籍法第13条で日本の国籍をはなれた人） | 2016〜2025年 |
| 確かめ.csv | 合計が内わけと合うか、累計が毎年の和と合うか、国籍別の表と推移の表が同じ数か | |

- どれも **暦年**（1月〜12月）の人数です。
- 申請者数・許可者数・不許可者数は、それぞれ **その年にあった数** です。その年に申請した人がその年に許可・不許可になったとは限らないので、許可者数÷申請者数は「許可される割合」にはなりません。
- ある年の始まり：帰化許可者数は1952年4月28日から（1952年4月28日〜1966年は1つにまとめた数で、「年」は `1952-1966`。1952年4月27日以前は合計の333人だけで、「年」は `-1952`）。申請者数は1969年から、不許可者数は1989年からです。
- 推移の表の国籍は「韓国・朝鮮」「中国」「その他」の3つだけです。くわしい国籍は 国籍別帰化許可者数.csv（2019年から）。
  - 法務省の「国籍別帰化許可者数」の PDF は、毎年新しい年の分に差しかわります（どの版も2〜3年分）。今のページにない前の版（2019〜2022年の分）は、インターネット・アーカイブ（web.archive.org）に保存された同じ PDF を `../download_kika.py` が落としています（`../元データ/帰化_出どころ一覧.csv` の「保存版のURL」）。法務省のページで国籍別の PDF が出たのは2021年ごろからで、2018年より前の国籍別（上位10）は見つかっていません。
  - 同じ年が2つ以上の版にあるときは、新しい版の数を使っています。2023年の「その他」は、前の版（001414947.pdf）では956人、新しい版では892人です（新しい版は、上位10と足すと総数と合います）。確かめ.csv に書いています。
  - 2019年の表は、同じ人数を同じ順位にしています（ロシアとアメリカ合衆国が47人で8位、9位はなし）。新しい版では同じ人数でも順位が分かれていることがあります（2020年のベトナムとフィリピンは301人で4位と5位）。表の「順位」は PDF のままです。
- 法務省の注記のとおり、2010年（平成22年）の帰化許可者数は官報の正誤（中国2人）を反映した数です。
- 確かめの結果：どの年も 合計＝韓国・朝鮮＋中国＋その他、累計（619,466人）＝毎年の合計の和、国籍別の表（2019〜2025年のどの年も）の 上位10＋その他＝総数、総数・韓国・朝鮮・中国＝推移の表の数 が合っています。PDF の画像とも、いくつかの年で見比べて同じでした。

| 申請時の在留資格.csv | 難民認定申請者の、申請したときの在留資格（正規滞在とその内わけ・不法滞在・総数。種別「正規滞在の内わけ」の行は正規滞在の内数） | 2016年〜2025年 |
| 処理の状況.csv | 一次審査（申請者数・処理数・認定・不認定・取下げ等・未処理数）、審査請求（審査請求数・処理数・理由あり・理由なし・取下げ等・未処理数）、人道配慮数と、うち本国情勢等 | 2010年〜2025年（人道配慮は2018年〜） |
| 確かめ.csv | 内わけの合計＝総数、表どうし（毎年の数・国籍別・審査の表）で同じ数か、同じ年の数が発表によって違わないか | |

- どれも **暦年**（1月〜12月）の人数です（シリア人留学生の受入れだけ年度）。
- **条約難民** は入管法にもとづいて難民と認定した人、**補完的保護対象者** は2023年12月1日に始まった制度で認定した人、**その他の保護** は難民などとは認定しなかったものの人道的な配慮で在留を認めた人（1991年から）、**定住難民** は1978〜2005年のインドシナ難民と2010年からの第三国定住難民です。
- **合計** は国の表の「合計」です。定住難民として受け入れたあと条約難民と認定された人や、一次審査で「その他の保護」としたあと審査請求で条約難民と認定された人などは、国の表の注のとおり重複して数えられています。
- 国の表で数が書かれていない所（斜線など）は、表に行を書いていません（0人とは分けています）。0人と書かれている所は0人です。
- 国籍別の難民認定申請者数の2018〜2020年は、発表が上位25か国・地域と「その他」だけです。2021年からは全部の国籍・地域がのっています（のっていない国籍・地域は0人）。難民認定者数・補完的保護対象者認定者数・人道配慮（本国情勢等）は、どの年も全部の国籍・地域がのっています。
- 同じ年の国籍別の表が何回かの発表にあるときは、のっている国籍・地域がいちばん多い版（同じなら新しい版）を使い、ほかの版とも数が同じか確かめています（出どころの列がその版）。
- 申請者数・認定者数・処理数は、それぞれ **その年にあった数** です。その年に申請した人がその年に審査されたとは限らないので、認定者数÷申請者数は「認定される割合」にはなりません。申請者数には、前にも申請したことのある人（複数回の申請）も入っています。
- 2023年からの一次審査の「不認定」には、国の表の注のとおり、難民認定の申請に対して補完的保護対象者と認定した人の数が入っています。処理の状況.csv の「うち補完的保護の申請」は、審査請求のうち補完的保護対象者の認定の申請に関するものです（内数）。
- 確かめの結果（280件）：毎年の数の表は、列ごとの合計が合計の行と同じで、どの年も 定住難民＋条約難民＋補完的保護対象者＋その他の保護＝合計。2020〜2024年の発表の同じ表とも、同じ年の数がすべて同じでした。
  国籍別はどの年・どの項目も 国籍・地域の合計＝総数 で、総数は毎年の数の表と同じ。一次審査の認定＋審査請求の理由あり（難民）＝条約難民（どの年も）。PDF の画像とも、いくつかの表で見比べて同じでした。

## 特定活動の在留目的（特定活動/）

在留外国人統計（旧登録外国人統計）の在留資格「特定活動」を、在留目的（活動の中身）ごとに分けた数です。作り方は `../make_tokutei.py`（e-Stat の表と、この フォルダの表から読み出して確かめる）。

| ファイル | わかること | ある時点 |
|---|---|---|
| 在留目的別.csv | 全国の在留目的ごとの数。在留目的は国の表の名前のまま（空白は除く）。「総数」は特定活動の合計 | 1990年末〜2025年12月末 |
| 国籍_在留目的.csv | 国籍・地域 × 在留目的（0人の行は書いていません。「うち中国〔香港〕」などの内わけの行は入れていません。無国籍は州の行の数） | 2022年12月末〜 |
| 確かめ.csv | 在留目的の合計＝総数か、総数＝在留資格の表の特定活動の数か、国籍ごとの合計＝全国の数か | |

- 読んだ表：1990〜2005年末は 古い表/全国_国籍_在留資格.csv（統計書の内わけは「ワーキング・ホリデー」と「その他」だけ）、2006〜2011年末は 全国_国籍_在留資格.csv、
  2012年12月末〜2023年6月末は「国籍・地域別 在留資格（在留目的）別 在留外国人」、2023年12月末からは「国籍・地域別 在留目的別 在留外国人（特定活動・日本人の配偶者等・定住者）」。
- 2012年12月末〜2022年6月末の表では、「ＥＰＡ対象者」「アマスポーツ選手」「高度人材」などの列が「本人」「家族」に分かれています。在留目的別.csv には両方を入れています（全国_国籍_在留資格.csv の特定活動の内わけの行には「家族」の列が入っていません。特定活動の合計の数は同じです）。
- 在留目的の名前と分け方は時点によって変わります。たとえば「本国情勢等」は2024年12月末から、「特定技能１号移行準備」「本邦の大学等卒業後の就職活動」「未来創造人材本人」などは2023年12月末から分けて数えられています。それより前は「その他」などに入っています。
- 「デジタルノマド本人」「デジタルノマド配偶者・子」は中長期在留者ではないため、国の表の注のとおり総数に入っていません（外数）。
- 確かめの結果：どの時点も 在留目的の合計＝総数、総数＝在留資格の表（全国_国籍_在留資格.csv・古い表）の特定活動の数、国籍ごとの合計＝全国の数 が合っています。

出入国在留管理庁「在留外国人統計（旧登録外国人統計）」（政府統計の総合窓口 e-Stat）を加工して作成
