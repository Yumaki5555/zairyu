# 数でみる在留外国人

**サイト：https://yumaki5555.github.io/zairyu/**

出入国在留管理庁が発表している在留外国人の数（在留外国人統計・旧登録外国人統計）を、国籍・在留資格・都道府県・市区町村ごとに見られるようにしたサイトと、その元にした表・作り方のプログラムです。
日本に住む外国人について考えるときの材料として作りました。数は国の発表のまま示し、良い・悪いの判断や、ある考えに導くような言い方はしていません。

- 1959年から2025年12月末までの数（1959〜2005年は紙の統計書のスキャンから読み取り、合計と照らし合わせたもの。数は印刷どおりで、統計書の中で合計が合わない所もそのまま残しています）
- 日本全体・47都道府県・市区町村（政令市の区も）・国籍と地域ごとのページ
- トップページのいちばん上に「グラフの画像を作る（X投稿用）」：何のグラフ（国籍・地域／在留資格／地域／国籍×在留資格）・どこの・だれの・いつ（開始・終了）を選ぶと、X投稿用の画像と投稿文ができます。1時点のグラフでは、確定統計より新しい法務省の半期速報（全国の国籍・地域／在留資格／都道府県ごと）も選べます（画像と投稿文に「（速報）」と速報の出典が入ります）
- トップページの「日本全体の在留外国人」（いまの人数・1年前から・10年前から）は、確定統計より新しい半期速報があれば、その速報の数を「（速報）」と書いて出します（1年前・10年前の数は確定統計）。新しい速報や確定統計を取り込んで make_site.py を動かすと、いちばん新しい方に自動で変わります
- 目的別の入口：地域から探す（名前で探す・日本地図）・国籍から探す・在留資格から探す。長い一覧は名前で探す・並べ替え・もっと見るができます
- 国籍・在留資格の内わけ（円グラフ・棒グラフ・表）、移り変わりの折れ線、日本と都道府県の地図
- 在留外国人統計とは別の統計のページ（メニューの「ほかの統計」）：帰化の数（法務省民事局、1952年〜）・不法残留者数（法務省の報道発表、2017年〜）・難民の認定と保護の数（出入国在留管理庁の報道発表、1978年〜。国籍・地域別は2018年〜）。半期速報と同じ形のダッシュボードで、国籍・在留資格・時点・期間を選んで見られます

## 入っているもの

| フォルダ・ファイル | 中身 |
|---|---|
| `docs/` | 公開しているサイトのページ（`make_site.py` が作ったもの。GitHub Pages でこのフォルダを公開） |
| `データ/` | 1行に1つの数が入った表（CSV）。説明は [データ/データの説明.md](データ/データの説明.md) |
| `データ/古い表/` | 1959〜2005年の表。説明は [データ/古い表/古い表の説明.md](データ/古い表/古い表の説明.md) |
| `元データ/` | 元のファイルの出どころ一覧（e-Stat・総務省・法務省の資料の URL）と、画像で確かめて直した所・印刷のまま残した所の一覧 |
| `site_assets/` | どのページでも使う動き（`app.js`：メニュー・上に戻る・一覧の操作・グラフ）・見た目（`style.css`）・画像の保存（`share.js`）・トップページの画像づくり（`xmaker.js`）・ダッシュボード（`dash.js`・`dash.css`）・半期速報（`sokuho.js`）・不法残留（`fuho.js`）・帰化（`kika.js`）・難民（`nanmin.js`）・特定活動の一覧の操作（`tokutei.js`）・地図の形（`map/`） |
| `*.py`・`*.ps1` | 作り方のプログラム |

元のファイル（e-Stat の Excel・PDF、国土地理院の地図のデータ）は大きく、出どころから取り直せるので入れていません。

## 作り方（作り直すとき）

Python 3 と pandas・openpyxl・xlrd・pbixray を使います（古い表の読み取りには pymupdf・RapidOCR・Pillow と Windows の文字の読み取りも）。

1. `python download_estat.py` … e-Stat から元のファイルを落とす（`元データ/` に入る）
2. `python make_data.py` … `データ/` の表を作り、表どうしの合計が国の発表の数と合うか確かめる（結果は `データ/検算.csv`）
3. 古い表（1959〜2005年）は `ocr_pdfs.py` → `make_old_data.py`（くわしくは古い表の説明）
4. `python make_map.py` … 地図の形を作る（先に国土地理院「地球地図日本」第2.1版の行政界を `元データ/地図/gm-jpn-bnd_u_2_1/` に置く）。
   `python make_world_map.py` … 「国籍から探す」の世界地図の形を作る（先に Natural Earth v5.1.2 の `ne_10m_admin_0_countries_jpn.geojson` を `元データ/地図/natural-earth/` に置く）
5. `python download_population.py` → `python make_population.py` … 外国人の割合の分母にする人口（総務省「住民基本台帳に基づく人口」）
6. `python download_press.py` → `python make_press.py` … 法務省の半期速報（報道発表の資料）。内わけの合計と、同じ時点の確定統計と同じかを確かめる
   `python download_fuho.py` → `python make_fuho.py` … 不法残留者数（報道発表の資料、`データ/不法残留/`）。
   `python download_kika.py` → `python make_kika.py` … 帰化の数（法務省民事局の PDF、`データ/帰化/`）。
   `python download_nanmin.py` → `python make_nanmin.py` … 難民認定などの数（報道発表の PDF、`データ/難民/`）。どれも内わけの合計などを確かめる（サイトの「不法残留」「帰化」「難民」のページに使う）
   `python download_nyukoku.py` → `python make_tokutei.py` … 在留資格「特定活動」の在留目的ごとの数と、新しく入国した人の入国目的ごとの数（e-Stat の在留外国人統計・出入国管理統計の表から、`データ/特定活動/`。サイトの「在留資格「特定活動」とは」のページに使う）
7. `python make_site.py` … `site/` にサイトのページを作る
8. `python make_dash_data.py` … ダッシュボードが読む小さな表（`site/data/*.json`）を作る
9. `python copy_public.py <写す先>` … 公開するものだけを写す（`site/` は `docs/` になる）。`upload_github.py` はこれをして GitHub に上げる

## 出典・利用の条件

- 出入国在留管理庁「在留外国人統計（旧登録外国人統計）」（政府統計の総合窓口 e-Stat、https://www.e-stat.go.jp/ ）を加工して作成。e-Stat の利用規約に従い、出典を示して使っています
- 人口：総務省「住民基本台帳に基づく人口、人口動態及び世帯数調査」（e-Stat）を加工して作成（外国人の割合の分母）
- 特定活動の新しく入国した人：出入国在留管理庁「出入国管理統計」（e-Stat）を加工して作成
- 半期速報：出入国在留管理庁「〇年〇月末現在における在留外国人数について」（報道発表、https://www.moj.go.jp/isa/ ）
- 不法残留者数：出入国在留管理庁「本邦における不法残留者数について（〇年〇月１日現在）」（報道発表、https://www.moj.go.jp/isa/ ）
- 帰化：法務省民事局「帰化許可申請者数等の推移」（https://www.moj.go.jp/MINJI/toukei_t_minj03.html ）
- 難民：出入国在留管理庁「令和〇年における難民認定者数等について」（報道発表、https://www.moj.go.jp/isa/ ）
- 地図：国土地理院「地球地図日本」（https://www.gsi.go.jp/kankyochiri/gm_jpn.html ）を加工して作成（国土地理院コンテンツ利用規約による）
- 世界地図：Natural Earth（https://www.naturalearthdata.com/ 、日本の見方の国境の版）を加工して作成（パブリックドメイン）

数を見るときの注意（2011年までと2012年からで数え方が違うことなど）は、サイトの「[このサイトについて](https://yumaki5555.github.io/zairyu/about.html)」にまとめています。
