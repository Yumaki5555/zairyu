法務省・半期速報

出入国在留管理庁が毎年6月末と12月末の数を発表する「在留外国人数について」（報道発表）の数です。 国籍・地域は発表にのっている上位だけ（2022年末までは上位10、2023年6月末からは上位20）で、市区町村の数はありません。 あとで e-Stat に出る確定統計とは別に記録し、速報確定統計の印で分けて示します。

このページの数について

  • 法務省の今のサイトにある発表（令和2年末〜）を取り込んでいます。それより前の発表は今のサイトにないため、入れていません。
  • 発表ごとに、資料の URL と公表日を記録しています。同じ時点の発表は1つだけ取り込み、前の発表の数を上書きしません。
  • 取り込むときに、内わけの合計が総数と合うか、同じ時点の確定統計（e-Stat）と同じかを確かめています。
  • 市区町村ごとの数や、国籍×在留資格のくわしい数はダッシュボード（確定統計）で見られます。
出典：出入国在留管理庁「在留外国人統計（旧登録外国人統計）」（政府統計の総合窓口 e-Stat）を加工して作成。地図：国土地理院「地球地図日本」を加工して作成。 数は国の発表のまま示しています。良い・悪いの判断はしていません。データは2025年12月末まで。ページを作った日 2026年10月22日。
