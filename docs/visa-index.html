在留資格から探す

対象：日本に住む外国人（全国、27の在留資格）集計時点：2025年12月末（確定した統計）

在留資格は、外国人が日本でどんな活動をして暮らすかを決める資格です（例：永住者、留学、技能実習）。資格の名前を押すと、ダッシュボードでその資格の人の地域・国籍・移り変わりが見られます。

在留資格の移り変わり（国籍・地域を選べます）

各年12月末の数。いちばん新しい年に多い在留資格7つと、それ以外を合わせた「その他」の線です。線の名前を押すと、その線を消したり出したりできます（残った線に合わせて目もりが変わります）。2015年4月より前の「投資・経営」は「経営・管理」に、「技術」と「人文知識・国際業務」は「技術・人文知識・国際業務」に、2010年7月より前の「就学」は「留学」にまとめて示しています。点線より左（2011年まで）は登録外国人統計で、数え方が違います（短い期間の滞在の人なども入ります）。

次に見る

  • 地域・国籍を選んで在留資格を見るダッシュボードの在留資格の内訳（都道府県・市区町村も）
  • 在留資格を増え方で並べるダッシュボードのランキング（5年間の増加率など）
  • 国籍×在留資格の組み合わせランキング「ベトナム（技能実習）」のように、国籍・地域と在留資格の組み合わせごとに並べる
  • 国籍から探す国籍・地域ごとの人数と、多い在留資格

在留資格のまとめ方

  • 「技能実習」「特定技能」「高度専門職」は、号ごとの細かい区分（1号・2号など）をまとめています。
  • 移り変わりの線では、名前が変わった在留資格を今の名前にそろえています（2015年4月より前の「投資・経営」は「経営・管理」、「技術」と「人文知識・国際業務」は「技術・人文知識・国際業務」、2010年7月より前の「就学」は「留学」）。
  • グラフ（円グラフ・棒グラフ・線の名前と、保存する画像）では、名前の長い「技術・人文知識・国際業務」を「技人国（ぎじんこく）」と短くしています。表では元の名前のままです。

出典・数を見るときの注意

  • 出典：出入国在留管理庁「在留外国人統計（旧登録外国人統計）」（政府統計の総合窓口 e-Stat）を加工して作成。
  • 2011年までと2012年からで数え方が違います。2011年までは「外国人登録をした人」（登録外国人統計）、2012年12月末からは「中長期在留者と特別永住者」（在留外国人統計）です。
  • 国籍・地域の名前は国の表のとおりです。ただし、2005年までの古い表で書き方が違うもの（「ヴェトナム」など）や名前が変わった国（「ビルマ」など）は、今の名前にそろえています。「韓国・朝鮮」は2015年6月末まで1つにまとめて数えられています。
  • 在留資格の「技能実習」「特定技能」「高度専門職」は、号ごとの細かい区分をまとめて示しています。
  • 使っているデータや数え方のくわしい説明はこのサイトについてにあります。
