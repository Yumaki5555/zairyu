このサイトについて

目的

日本に住む外国人について考えるときの材料として、国（出入国在留管理庁）が発表している数を、国籍・在留資格・都道府県・市区町村ごとに見やすくしたサイトです。 数はそのまま示し、良い・悪いの判断や、ある考えに導くような言い方はしていません。

使っているデータ

  • 出入国在留管理庁「在留外国人統計」（2012年12月末〜2025年12月末）。2013年からは6月末と12月末の年2回
  • 同「登録外国人統計」（1959〜2011年末。2011年までの数え方）。1959〜2005年は紙の統計書のスキャンしかないため、画像から数字を読み取りました。 数は印刷どおりです。表の中の合計と照らし合わせ、合わない所は画像で確かめています。元の統計書の中で合計が合っていない所（印刷のずれ）は、合わせるために数を変えず、印刷のまま残しています。 読み取れなかったマスの一部は、表の合計から求めた数です（どのマスかは GitHub の表の「直した所」にあります）
  • どちらも政府統計の総合窓口（e-Stat）で公開されているものです
  • 外国人の割合の分母：総務省「住民基本台帳に基づく人口、人口動態及び世帯数調査」（日本人住民と外国人住民の合計、各年1月1日現在。2014年から）。12月末の在留外国人の数を、翌年1月1日の人口で割っています
  • 半期速報：出入国在留管理庁の報道発表「〇年〇月末現在における在留外国人数について」（令和2年末から）。確定統計とは別に示しています
  • 不法残留者数：出入国在留管理庁の報道発表「本邦における不法残留者数について」（2021年1月1日現在の発表から）。在留外国人統計とは別の統計です
  • 帰化の数：法務省民事局「帰化許可申請者数等の推移」（1952年から）。在留外国人統計とは別の統計です
  • 難民の認定と保護の数：出入国在留管理庁の報道発表「令和〇年における難民認定者数等について」（2020年の数の発表から。毎年の数は1978年から）。在留外国人統計とは別の統計です
  • 在留資格「特定活動」とは：在留外国人統計の「特定活動」の在留目的ごとの数（2012年12月末から）、出入国在留管理庁「出入国管理統計」の新しく入国した人の入国目的ごとの数（2024年から）と、入管法・特定活動告示・出入国在留管理庁などの資料からまとめた説明
  • 在留資格「定住者」とは：在留外国人統計の「定住者」の区分（日系３世・配偶者・未成年未婚の実子・その他）ごとの数（2023年12月末から）、出入国管理統計の新しく入国した人の区分ごとの数（2024年から）と、入管法・定住者告示・出入国在留管理庁の資料・国会の会議録からまとめた説明

数を見るときの注意

  • 2011年までと2012年からで数え方が違います。2011年までは「外国人登録をした人」（短い期間の滞在の人なども入る）、2012年12月末からは「中長期在留者と特別永住者」です。つなげて増え方を見るときは注意してください。
  • 市区町村ごとの数は、2023年6月末までは主な国籍だけ、2023年12月末からは全部の国籍が公表されています。
  • 外国人が10人以下の市町村は、国の表で次のように扱われています。2019年12月末〜2023年6月末は、在留資格別の表にのっていません（非表示）。 2023年12月末・2024年6月末は、全国で1つの「その他」にまとめられていて、市町村ごとの数がありません。2024年12月末からは、人数は出ますが国籍・在留資格が公表されていません（このサイトでは「公表されていない」と示します）。
  • 「0人」と「データなし」は分けています。国の表にその区分がない時点（「韓国」と「朝鮮」を分けずに数えていた2015年6月末まで、など）や、国の表にその市区町村がのっていない時点（外国人が10人以下の市町村など）は「データなし」とし、0人にはしていません。ダッシュボードでは、線を押すと理由が出ます。
  • 日本全体の数と、都道府県の数の合計は少し違います。住む所が「未定・不詳」の人は、日本全体の数にだけ入っているためです（2025年12月末は7,228人）。
  • 政令指定都市の数は、国の表の市の合計です。市の合計がない時点は、その時点にあった区の合計です（浜松市は2024年1月に7つの区が3つの区になりました。2023年12月末は前の7つの区の合計です）。政令指定都市になる前の年は、その市の数です。2016年6月末の熊本市は、国の表の市の合計が0人になっていますが、区の合計（4,704人）を使っています。
  • 市町村の名前が変わった所（篠山市→丹波篠山市、滝沢村→滝沢市など）や、国の表で字が違う所（諌早市→諫早市、八丈島八丈町→八丈町など）は、今の市町村の数としてつなげています。浜松市天竜区は2024年1月に番号が変わりましたが、区の範囲は同じなのでつなげています。ほかの市町村と合併して範囲が変わった所（鳩ケ谷市など）はつなげていません。
  • 在留資格の「技能実習」「特定技能」「高度専門職」は、号ごとの細かい区分をまとめて示しています。
  • 国籍・地域の名前は国の表のとおりです。ただし、2005年までの古い表で書き方が違うもの（「ヴェトナム」など）や名前が変わった国（「ビルマ」など）は、今の名前にそろえています。「韓国・朝鮮」は2015年6月末まで1つにまとめて数えられています。 2006〜2018年の表でも、同じ国の書き方の違い（「カーボヴェルデ」など）、名前が変わった国（「グルジア」→「ジョージア」）、元の表のマスで文字の順が入れ替わっていたもの（「・トバゴトリニダード」）、中点が半角のもの（「韓国･朝鮮」）は、今の名前にそろえています（一覧は GitHub の「データ/国籍・地域の名前の直し.csv」）。
  • 地図の形は、国土地理院「地球地図日本」（2015年1月1日時点の市区町村の境界）を加工して作ったものです。その後に町や村から市になってコードが変わった所は、今のコードに合わせています。日本全体の地図では、沖縄県を左上の枠の中に移して1.3倍の大きさにし、小笠原諸島は入れていません。東京都の地図には伊豆諸島・小笠原諸島を入れていません。
  • 「国籍から探す」の世界地図の形は、Natural Earth（日本の見方の国境の版）を加工して作ったものです。太平洋を真ん中にし、南極は入れていません。小さな国は丸で示しています。 国の表の「朝鮮」は国籍を表すものではないため、地図には色を付けていません。香港の人は、国の表では「中国」と「英国」に分かれて入っているため、香港だけの色は付けていません。
  • 日本全体の地図の「四角で並べる」は、都道府県を同じ大きさの四角で、おおよその位置に並べたものです（面積や形は表していません）。
  • 在留資格の移り変わりの線では、名前が変わった在留資格を今の名前にそろえています（2015年4月より前の「投資・経営」は「経営・管理」、「技術」と「人文知識・国際業務」は「技術・人文知識・国際業務」、2010年7月より前の「就学」は「留学」）。
  • グラフ（円グラフ・棒グラフ・線の名前と、保存する画像）では、名前の長い「技術・人文知識・国際業務」を「技人国（ぎじんこく）」と短くしています。表では元の名前のままです。

表と作り方

このサイトのページ、元にした表（1行に1つの数が入った CSV）、作り方のプログラムは、GitHub で公開しています： https://github.com/Yumaki5555/zairyu。表は自由に取り出して使えます（使うときは下の出典を書いてください）。

出典の書き方

出入国在留管理庁「在留外国人統計（旧登録外国人統計）」（政府統計の総合窓口 e-Stat）を加工して作成

地図：国土地理院「地球地図日本」（https://www.gsi.go.jp/kankyochiri/gm_jpn.html）を加工して作成（国土地理院コンテンツ利用規約による）

世界地図：Natural Earth（https://www.naturalearthdata.com/）を加工して作成
