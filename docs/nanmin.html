難民の認定と保護の数

日本で難民と認定された人、難民に近い立場として保護された人、難民の認定を申請した人などの数です。出入国在留管理庁が毎年、前の年（1月〜12月）の数を発表しています。 在留外国人の数（在留外国人統計）とは別の統計です。 申請の流れや、手続き中に働けるか・住民票や健康保険・税金・家族などの決まりは難民の申請と、手続き中のくらしにまとめています。

対象：日本全体期間：1978年〜2025年（毎年1月〜12月の人数。2026年3月27日公表の発表まで）

このページの内容：① その年の数と累計② 国籍・地域別③ 選んだ国籍・地域④ 申請したときの在留資格⑤ 移り変わり⑥ 審査の進み方⑦ くわしい数⑧ 出典と注意

「対象の年」を変えると、その年の数と、その年までの累計に変わります。選んだ条件はこのページのアドレスに残るので、アドレスを送れば同じ画面を見てもらえます。どの図も「画像を保存」で X投稿用の画像にできます。

出典と、数を見るときの注意

出典と注意を開く
  • 出典：出入国在留管理庁「令和７年における難民認定者数等について」など（報道発表）を加工して作成。毎年の数は「我が国における難民保護の状況等」の表（いちばん新しい発表のもの）、国籍・地域別・申請したときの在留資格・審査の数は、本文と別表の表から読みました。
  • どれも暦年（1月〜12月）の人数です（シリア人留学生の受入れだけ年度）。
  • 条約難民：入管法にもとづいて、難民条約の難民（人種・宗教・国籍・特定の社会的集団の構成員であること・政治的意見を理由に、迫害を受けるおそれがある人）に当たると認定された人。 一次審査で認定されず、審査請求（2016年3月までは異議申立て）で認定された人も入ります（その人数は「うち審査請求で認定」）。
  • 補完的保護対象者：難民条約の5つの理由には当たらないものの、難民と同じように迫害を受けるおそれがあるとして認定された人（紛争から逃れてきた人など）。2023年12月1日に始まった制度です。
  • その他の保護（人道配慮）：難民や補完的保護対象者とは認定しなかったものの、人道的な配慮を理由に在留を認めた人（1991年から）。本国の情勢などをふまえたものと、日本人と結婚しているなど日本での事情をふまえたものがあります。 国の表のとおり、難民認定などの手続きの結果が出る前に、本国の情勢をふまえて在留を先に認めたミャンマーの人などが入っています。
  • 定住難民：政府の決定（閣議了解）にもとづいて受け入れた難民。1978〜2005年はインドシナ難民（ベトナム・ラオス・カンボジアから周辺の地域へ逃れた人と、呼び寄せた家族）、2010年からは第三国定住難民（国の表の注では、タイまたはマレーシアから受け入れたミャンマーの難民）です。
  • 合計は国の表の「合計」です。定住難民として受け入れたあと条約難民と認定された人や、一次審査で人道配慮となったあと審査請求で難民と認定された人などは、重複して数えられています。そのため、区分の数を足した数と合計は、国の表のとおり同じですが、人の数としては重複があります。
  • 国籍・地域別の数は2018年からです。難民認定申請者数の2018〜2020年は、発表が上位25か国・地域と「その他」だけなので、上位25の外の国籍・地域の数は分かりません（0人ではありません）。2021年からは全部の国籍・地域がのっているので、のっていない国籍・地域は0人です。
  • 申請者数・認定者数・処理数は、それぞれその年にあった数です。その年に申請した人がその年に審査されたとは限らないので、このページでは認定者数÷申請者数を「認定される割合」としては出していません。 審査の進み方の割合は、その年に審査を終えた人（処理数）の内わけです。
  • 申請者数には、前にも申請したことのある人（複数回の申請）も入っています。
  • 取り込むときに、内わけの合計が総数と合うか、表どうし（毎年の数の表・国籍別の表・審査の表）で同じ数か、同じ年の数が発表によって違わないかを確かめています（280件。合わないもの 0件）。
  • 表（1行に1つの数の CSV）は GitHub の「データ/難民/」にあります：https://github.com/Yumaki5555/zairyu
