在留資格「定住者」とは

「定住者」は、法務大臣が特別な理由を考えて、一定の在留期間を決めて日本に住むことを認める在留資格です。 日系3世、日系人などの夫や妻、日本人などと結婚した外国人の連れ子、難民と認定された人、日本人と離婚したあとも日本で子を育てる人など、中身はさまざまです。 このページでは、どんな資格か・いつできたか・どんな人が何人いるか（国の表の「その他」の中身も）を、法務省（出入国在留管理庁）の資料と統計からまとめました。

どんな資格？

在留資格は、外国人が日本でどんな活動をして暮らせるかを決めたものです（例：留学、永住者、技能実習）。 「定住者」は、入管法（出入国管理及び難民認定法）で「法務大臣が特別な理由を考慮し一定の在留期間を指定して居住を認める者」とされています。 仕事の中身で決まる在留資格（留学・技能実習など）ではなく、身分や立場で決まる在留資格（永住者・日本人の配偶者等などと同じなかま）です。

  • 働くことに制限はありません。仕事の種類や時間の制限は、仕事の中身で決まる在留資格の人だけにあります（入管法第19条）。
  • 在留期間は、5年・3年・1年・6月、または法務大臣が一人ひとりに決める期間（5年まで）です。
  • 2つの種類があります。
    ① 告示で前もって決めた人：法務省の告示（「定住者告示」、平成2年法務省告示第132号）に、日系3世や第三国定住難民などが号ごとに書かれています（1号〜8号。2号は削除されています）。 外国から新しく「定住者」で日本に来られるのは、原則としてこの告示にある人だけです（入管法第7条第1項第2号）。
    ② 告示にない人：すでに日本にいる人が、ほかの在留資格から変えるときなどに、法務大臣が一人ひとりの事情を見て認めるものです。 難民と認定された人や、日本人と離婚したあとも日本に住む人などがあります。

「その他」には何が入っている？

国の表の「その他」（2025年12月末に77,519人）は、定住者のうちいちばん多い区分です。 国の表の利用上の注意に、2024年6月末から「表にない定住者の告示と、告示にない定住者は『その他』に入れる」と書かれています。 国は「その他」の内わけを発表していないので、それぞれの人数は分かりません。

告示にあるが、国の表で分けていないもの

  • 第三国定住難民

    アジアの21の国に一時的にいる難民のうち、国連難民高等弁務官事務所（UNHCR）が保護が必要と認めて日本に推薦した人と、その家族。

    定住者告示 1号

  • 6歳未満の養子

    日本人・永住者・特別永住者・在留期間が1年以上の定住者に養われて暮らす、6歳未満の養子。

    定住者告示 7号

  • 中国残留邦人とその家族

    1945年8月9日以後の混乱などで日本に引き揚げられず、中国に住み続けた日本人（中国残留邦人）とその子や、日本に永住帰国した中国残留邦人と一緒に暮らすために来る配偶者・子など。

    定住者告示 8号

第三国定住で受け入れた難民は、2010年から2025年までに337人です（難民の認定と保護の数の「定住難民」。いま定住者として住んでいる人の数ではありません）。

告示にないもの（法務大臣が一人ひとりの事情を見て認めるもの）

たとえば、次のような人がいます。

  • 難民・補完的保護対象者と認定された人

    難民と認定された人と、補完的保護対象者（難民条約の5つの理由には当たらないものの、迫害を受けるおそれがあるとして認定された人。2023年12月から）には、入管法で、決められた罪を犯した人などをのぞき「定住者」を許可することになっています（第61条の2の2・第61条の2の3）。2025年までに認定された人は、難民（条約難民）が1,797人（1982年から）、補完的保護対象者が2,137人（2023年から）です（認定した人の数で、いま定住者として住んでいる人の数ではありません）。

    出典：入管法（e-Gov 法令検索）・出入国在留管理庁「令和7年における難民認定者数等について」

  • 難民とは認められなかったが、人道上の配慮で在留を認められた人

    難民とは認定されなかったものの、人道上の配慮で在留を認められた人には、「定住者」か「特定活動」が許可されます（2013年11月27日の国会での政府の答弁）。人道上の配慮で在留を認めた人（その他の保護）は、2025年に525人です（「定住者」と「特定活動」の内わけは発表されていません）。

    出典：衆議院外務委員会（2013年11月27日）・出入国在留管理庁「令和7年における難民認定者数等について」

  • 日本人・永住者などと離婚した人、配偶者が亡くなった人

    日本人・永住者・特別永住者の配偶者として住んでいた外国人が、離婚したあとや、配偶者が亡くなったあとも日本に住み続けるとき、在留資格を「定住者」に変えることが認められる場合があります。法務省入国管理局（いまの出入国在留管理庁）は、認められた例と認められなかった例を公表しています（2012年7月。2017年3月改訂）。国会では、生計を立てる資産や技能があるか、日本人や永住者との間の子を日本で育てているかなどを総合的に考えて判断し、子がいなくても日本にかなり定着していれば認めている、と答弁されています（2009年6月30日）。

    出典：出入国在留管理庁（認められた例・認められなかった例）・参議院法務委員会（2009年6月30日）

  • 日本人の子を育てている外国人の親

    日本人と結婚していない外国人が、日本人との間に生まれた子（日本人の実子）を育てている場合など、人道的な配慮が必要と認められるときに、事情を考えて「定住者」が認められる場合があります（2018年12月6日の国会での政府の答弁）。

    出典：参議院法務委員会（2018年12月6日）

  • 配偶者からの暴力（DV）の被害を受けた人

    法務省入国管理局は2008年7月に「DV事案に関する措置要領」をつくりました。2009年5月末までに被害を申し立てた外国人40人のうち、在留資格を変えたのは9人で、7人が「定住者」、2人が「特定活動」でした（2009年6月30日の国会での政府の答弁）。

    出典：参議院法務委員会（2009年6月30日）

告示にない定住者は、決まった一覧も、審査のくわしい基準（入管の内部の「在留審査要領」）も、国から公開されていません。 行政書士の解説には、ほかに特別養子の縁組を解消した人や、頼れる家族のいない未成年の子なども挙げられていますが、国の公開資料では確かめられませんでした（例：ワンツーコール行政書士事務所のページの左の一覧）。 外国から新しく「定住者」で来られるのは原則として告示にある人だけなので、告示にない定住者の多くは、日本に来たあとにほかの在留資格から変えた人などです（下の「新しく来た人」）。

外国から新しく来た人は？（2025年の1年間）

2025年の1年間に、外国から新しく「定住者」で日本に来た人は8,860人でした（2024年は11,248人）。 入管法で、外国から新しく「定住者」で来られるのは原則として告示にある人だけなので、「その他」には、表で分けていない告示の人（第三国定住難民・6歳未満の養子・中国残留邦人とその家族）などが入ります。

定住者の数や中身にかかわる、法律・告示・取扱いの主な変わり目です。どれも法務省・出入国在留管理庁の資料や国会の会議録からまとめました。

1989年12月入管法の改正（平成元年法律第79号、12月15日公布）。在留資格を全面的に見直し、「定住者」（法務大臣が特別な理由を考えて、一定の在留期間を決めて住むことを認める人）ができる
出典：衆議院「制定法律」
1990年6月改正した入管法と、定住者の地位を前もって決めた告示（平成2年法務省告示第132号）が動き出す
出典：出入国在留管理庁「外国人労働者に関する制度概要」・定住者告示
2005年5月難民と認定された人に「定住者」を許可するしくみができる（2004年の入管法の改正、平成16年法律第73号）
出典：衆議院「制定法律」
2008年7月法務省入国管理局が「DV事案に関する措置要領」をつくる
出典：参議院法務委員会（2009年6月30日）
2009年4月厚生労働省の「日系人離職者に対する帰国支援事業」。支援金を受けて帰国した人は、当分の間（原則3年をめど）、日系人などの身分による在留資格では入国できないこととされた
出典：衆議院法務委員会（2009年6月19日）
2010年第三国定住による難民の受入れが始まる
出典：出入国在留管理庁「令和7年における難民認定者数等について」
2012年7月「日本人の配偶者等」「永住者の配偶者等」から「定住者」への変更が認められた例・認められなかった例を公表（2017年3月改訂）
出典：出入国在留管理庁
2021年10月いちばん新しい定住者告示の改正（法務省告示第220号、10月28日）
出典：定住者告示
2022年4月成年の年齢の引下げで、告示6号の「未成年」が20歳未満から18歳未満になる
出典：出入国在留管理庁「定住者」
2023年12月補完的保護の制度が始まり、補完的保護対象者と認定された人にも「定住者」を許可する（2023年の入管法の改正、令和5年法律第56号）
出典：衆議院「制定法律」・入管法（e-Gov 法令検索）

出典と、数を見るときの注意

出典と注意を開く
  • 人数：出入国在留管理庁「在留外国人統計（旧登録外国人統計）」（政府統計の総合窓口 e-Stat）。1990〜2005年末は統計書の「定住者」、2006〜2011年末は都道府県・国籍ごとの表、2012年12月末からは在留資格別の表です。 区分ごとの数は、2023年12月末からの「国籍・地域別 在留目的別 在留外国人（特定活動・日本人の配偶者等・定住者）」の表です。速報は出入国在留管理庁の報道発表「在留外国人数について」です。
  • 新しく来た人の数：出入国在留管理庁「出入国管理統計」（e-Stat）の「国籍・地域別 入国目的別 新規入国外国人（短期滞在・特定活動等）」（年に1回、1年間の数。2024年から）。見出しに定住者告示の号が書かれている表です。
  • 国の表の区分の名前は、2023年12月末の表では「日系３世（告示３・４号）」のように告示の号つき、2024年6月末からは号のない名前です。中身は同じものとして並べています。
  • 難民の認定・補完的保護・人道上の配慮・第三国定住の数：出入国在留管理庁の報道発表「令和〇年における難民認定者数等について」（難民の認定と保護の数と同じ表）。どれもその年に認定・受入れをした人の数で、いま定住者として住んでいる人の数ではありません。
  • 説明の文は、入管法（e-Gov 法令検索）、定住者告示（出入国在留管理庁、最近の改正 令和3年10月28日法務省告示第220号）、 在留資格「定住者」のページ（出入国在留管理庁）と、「「その他」には何が入っている？」「主な出来事」に書いた出典（出入国在留管理庁の資料、国会の会議録）から。
  • 表にない告示の号と告示にない定住者が「その他」に入ることは、在留外国人統計の利用上の注意から。
  • 取り込むときに、どの時点も 区分の合計＝定住者の合計、定住者の合計＝在留資格の表の定住者の数、国籍ごとの合計＝全国の数 になっているかを確かめています。 新しく来た人の表も、区分の合計＝定住者の合計、国籍ごとの合計＝全国の数 になっているかを確かめています（make_teiju.py）。
  • 表（1行に1つの数の CSV）は GitHub の「データ/定住者/」にあります：https://github.com/Yumaki5555/zairyu
