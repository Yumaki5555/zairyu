帰化の数

帰化は、外国の国籍の人が法務大臣の許可を受けて日本の国籍を取ることです。法務省民事局が発表している、毎年（1月〜12月）の帰化の人数をまとめました。 帰化して日本の国籍になった人は、在留外国人の数には入りません。

対象：日本全体期間：1952年〜2025年（毎年1月〜12月の人数。1966年まではまとめた数）

このページの内容：① これまでの累計② 国籍別③ 毎年の推移④ くわしい数⑤ 出典と注意

「対象の年」を変えると、その年までの累計と、その年の数に変わります。選んだ条件はこのページのアドレスに残るので、アドレスを送れば同じ画面を見てもらえます。どの図も「画像を保存」で X投稿用の画像にできます。

出典と、数を見るときの注意

出典と注意を開く
  • 出典：法務省民事局「帰化許可申請者数等の推移」を加工して作成（https://www.moj.go.jp/MINJI/toukei_t_minj03.html）。
  • どれも暦年（1月〜12月）の人数です。
  • 発表の数は、範囲が3つあります。このページでは混ぜずに示しています。 毎年の合計：帰化許可者数は1952年から（1952年4月27日以前は合計だけ、1952年4月28日〜1966年はまとめた数、1967年から毎年）。申請者数は1969年から、不許可者数は1989年から。 国籍の3区分（韓国・朝鮮／中国／その他）：1952年4月28日から。1952年4月27日以前の333人は区分がないので、どの国籍にも入れていません。 くわしい国籍：2019年から、毎年の上位10か国・地域だけ。
  • 累計（619,466人など）は、過去に帰化を許可された人数を足し合わせた数です。いま生きている人や、いま日本に住んでいる人の数ではありません。
  • くわしい国籍をいくつかの年で足した数は、各年の上位10にのった人数だけを足した「掲載分」です。上位10に入らなかった年の人数は分からないので足していません（0人として扱ってはいません）。そのため順位は付けていません。
  • 2010年の帰化許可者数は、法務省の注記のとおり、官報の正誤（中国2人）を反映した数です。
  • 国籍別の上位10の2019〜2022年は、法務省のページに前にのっていた PDF を、インターネット・アーカイブ（web.archive.org）に保存された版から読んだものです。 同じ年が2つ以上の版にあるときは、新しい版の数を使っています（2023年の「その他」は、前の版では956人、新しい版では892人。新しい版は、上位10と足すと総数と合います）。
  • 取り込むときに、どの年も 許可者数の合計＝韓国・朝鮮＋中国＋その他 になっているか、累計が毎年の数の和と同じか、国籍別の表と毎年の表が同じ数かを確かめています。
  • 表（1行に1つの数の CSV）は GitHub の「データ/帰化/」にあります：https://github.com/Yumaki5555/zairyu
