不法残留者数

在留期間が過ぎたあとも日本から出国していない外国人の数です（国の発表のことばで「不法残留者」）。出入国在留管理庁が毎年1月1日と7月1日の数を発表しています。 在留外国人の数（在留外国人統計）とは別の統計で、在留外国人の数には入っていません。

対象：日本全体時点：2026年7月1日現在（2026年10月16日公表の発表。移り変わりは2017年1月1日から）

すぐ下の欄で「時点」と「国籍・地域」を選ぶと、ページ全体が切り替わります。選んだ条件はこのページのアドレスに残るので、アドレスを送れば同じ画面を見てもらえます。どの図も「画像を保存」で X投稿用の画像にできます。

出典と、数を見るときの注意

出典と注意を開く
  • 出典：出入国在留管理庁「本邦における不法残留者数について」（報道発表）を加工して作成。
  • 不法残留者は、入管法第24条の不法残留の規定に当たる人です。国が出入国の記録と退去強制の手続きの情報などから出した概数です。
  • 時点は1月1日と7月1日です（2020年までは1月1日だけ）。在留外国人統計（6月末・12月末）とは時点も数え方も違うので、そのまま足したり割ったりできません。
  • 国籍・地域は、発表ごとの上位10か国・地域だけです。上位の顔ぶれは発表ごとに変わるので、「その他」に入っている国は発表によって違います。上位10に入っていない時点の数は「公表データなし」「—」で、0人ではありません。
  • ただし、新規不法残留者の表（2026年1月1日現在の発表から）は、新規の人の多い国籍・地域ごとに「その時点の数」「前の時点の数」ものせています。上位10に入っていない時点でも、この表にのっている数は使っています（同じ統計の同じ時点の数です。表では※を付けています）。
  • 在留資格は、不法残留になったときにもっていた在留資格です。技能実習の号（1号・2号・3号、イ・ロ）の数は技能実習の内数です。
  • 「新規」は、前の時点のあと（その半期など）に新しく分かり、基準日にも不法残留している人です。「減少」は、前の時点にいた人のうち基準日までに数から外れた人で、送還された人だけではありません（出国命令で出国した人、在留特別許可を受けた人なども入ります）。新規・減少は、総数の増減とは別の数です。比べる前の時点は発表ごとに違います（2026年1月1日現在の発表は1年前の2025年1月1日、2026年7月1日現在の発表は半年前の2026年1月1日。発表の表のとおり）。
  • 同じ時点の数は、どの発表でも同じでした（あとから直された数はありません）。取り込むときに、内わけの合計が総数と合うかも確かめています。
  • グラフの色は、国籍・地域ごと・在留資格ごとに決めていて、ページのどのグラフでも同じです。色は7つなので、8つ目からの国籍・地域は同じ色の点線（棒はしま模様）で分けています。
  • 表（1行に1つの数の CSV）は GitHub の「データ/不法残留/」にあります：https://github.com/Yumaki5555/zairyu
